# Example data

JSONL manifests used by the bundled suite configs in `../../configs`. Each line
is one evaluation example. The fields an example uses depend on the task type.

## Common fields

| Field | Meaning |
| --- | --- |
| `id` | Unique example identifier (required) |
| `audio` | Optional path to the source audio file |

## ASR (`asr.jsonl`)

| Field | Meaning |
| --- | --- |
| `reference` | Ground-truth transcription; a string or a list of acceptable strings |
| `prediction` | Optional stored hypothesis; generated by the adapter when absent |

## SED (`sed.jsonl`)

| Field | Meaning |
| --- | --- |
| `reference` | List of `{onset, offset, label}` events |
| `prediction` | Optional list of predicted events |

## AQA (`aqa.jsonl`)

| Field | Meaning |
| --- | --- |
| `question` | The question asked about the audio |
| `reference` | Ground-truth answer |
| `prediction` | Optional stored answer |

The `audio` paths are illustrative: the bundled examples score stored or
adapter-generated predictions and never read the audio files themselves.
